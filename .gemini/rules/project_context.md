# Antigravity Workspace Auto-Context Rule

每次启动新的对话会话（Session）或子 Agent 时，必须遵循以下规则：

1. **自动读取中枢记忆**：在执行任何代码分析、开发或修改之前，必须首先完整读取工作区根目录下的 `PROJECT_MEMORY.md`。
2. **遵守架构规范**：开发实现必须严格遵从 `科研助手Agent产品开发与工程落地手册.md` 中定义的分层架构、接口协议、内存限制与防幻觉设计。
3. **保持中枢更新**：当你的模块开发完成或有新的架构决策与踩坑记录时，必须同步将状态和结果追加更新至 `PROJECT_MEMORY.md`。
